## Project rules
- Business info, menu and image paths live in `src/data/*.ts` — edit data there, never hardcode in components (owner edits without touching UI).
- Item images resolve from `src/data/imagens.ts`; `ItemImage` must always render a fallback so no broken image shows.
- Service worker is generated by vite-plugin-pwa and registered only via `src/lib/pwa.ts` (guarded off in dev/preview).
- Orders are sent as WhatsApp messages; there is no backend.
